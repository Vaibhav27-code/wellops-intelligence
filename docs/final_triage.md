# Final-question triage

Dataset: [FlytBase official final test dataset](https://github.com/FlytBaseAILabs/flytbase-ahc-swe-asset-intelligence-dataset), loaded in the isolated demo DB. Dataset guide reference date: 2027-01-15. The rules-only API run covered all 21 turns in the 11-question set. Status describes what the current app can answer from this data, not whether the raw source material exists.

| Question | Status | What data exists | Known gaps in the current app |
|---|---|---|---|
| Q1. Reservoir pressure | Cannot be answered | Well metadata, inspections, operator context, maintenance, and regulatory records were scanned across the dataset. | No reservoir-pressure, pressure/PSI/bar, or equivalent measurement field was found. The rules path asked for clarification and returned no evidence. |
| Q2. Best producer | Cannot be answered | Inspections include temperatures and spill volumes; well metadata includes recorded status. | No oil-production volume or production-rate field was found, so wells cannot be ranked by oil produced in 2026. The rules path returned no evidence. |
| Q3. Gas reports | Partly | Operator notes, inspection timestamps/methods, maintenance start times, and operating SOPs exist. An independent keyword scan found candidate gas notes, including reports after the SOP deadline change. | `/chat` did not produce the required per-report response/deadline table. Candidate identification and matching to the earliest qualifying response need a tested deterministic tool and cited output. |
| Q4. Temporary flowline bypasses | Partly | Operator notes describe bypass events; MOC memos provide approval and expiry information. An independent scan identified candidate events. | `/chat` did not identify active, expired, and unapproved events or join them to the correct approvals. Event pairing and approval scope need a tested, cited tool. |
| Q5. Regulator letter | Partly | Spill inspections, cleanup/maintenance records, regulatory records, the commission letter, and cleanup instructions are present. | The run returned a broad 2026 spill-volume summary with hundreds of citations, not the spills covered by the letter or per-spill compliance reasons. Letter scope and cleanup evidence are not joined in the answer. |
| Q6. Which status is right? | Partly | Each well has inspection history, operator notes, well type, and manual-derived production thresholds. | The field-wide latest-inspection versus latest-note comparison was not returned. The query needs a deterministic conflict table with both timestamps, evidence, and an unconfirmed status where appropriate. |
| Q7. What the operators are hearing | Partly | Operator notes, maintenance jobs, repair reports, well areas, and dates exist. | The first turn returned a spill-volume ranking instead of a note-grounded repair-risk ranking; the crew-priority follow-up returned a clarification. A general, transparent ranking rule and its evidence are missing. |
| Q8. Who told you that? | Partly | Supplier recall documents, well/equipment records, maintenance costs, shared corrections, and private per-user memory storage exist. | The multi-session run did not correctly track the recall correction, private formatting preference, cross-user claim conflict, or recalled-pump installation costs. Several turns returned clarification or unrelated status wording. |
| Q9. One conversation, several topics | Partly | Teams/users, SOPs, operator notes, inspections, maintenance history, recall documents, and private session history are available. | Context linking across topics and turns is incomplete. In particular, the H2S question received a production-status answer; team recall, cold-weather evidence, recalled-pump status, repairs, and the final prioritization are not reliably answered together. |
| Q10. What are we waiting on? | Partly | Maintenance records include start/completion dates, downtime hours, issues, actions, and costs; inspections support status-derived downtime. | The run returned downtime totals by area, not the requested waiting reason shares, typical extra days, or stacked bar. Repair duration and shut-in duration are not compared by cause in the current answer path. |
| Q11. Hotter wells | Partly | Inspections contain ambient and wellhead temperatures; well metadata maps wells to areas and teams. | The app did not compute a repeated regional temperature comparison or return supporting data/citations. A deterministic aggregation and a clear definition of “consistently” are needed. |
